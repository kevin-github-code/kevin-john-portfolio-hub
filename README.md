# Kevin John Portfolio Hub

Cria um site de portefólio profissional de página única para um profissional de TI de Moçambique chamado Kevin John.

PERFIL

- Técnico de Informática (Suporte Informático, Administração de Sistemas e Programação)

- Maputo, Moçambique

- Estudante de Informática de Gestão (3.º ano)

- Idiomas: Português (nativo), Inglês (fluente), Espanhol e Francês (básico)

ESTILO

- Moderno, limpo e profissional, com tema escuro por defeito e opção de tema claro

- Cor de destaque: [teal / azul / a tua escolha]

- Tipografia sem serifa, muito espaço em branco, animações suaves ao fazer scroll

- Totalmente responsivo, optimizado para telemóvel

- Alternador de idioma PT / EN no topo, com todo o conteúdo nos dois idiomas

SECÇÕES (por esta ordem)

1. Hero: nome, título profissional, frase curta de apresentação, botões "Ver projectos", "Descarregar CV" e "Contacto"

2. Sobre mim: parágrafo curto e três cartões: Suporte Informático, Administração de Sistemas, Desenvolvimento

3. Projectos: grelha de cartões com título, descrição curta, etiquetas de tecnologias e botão que abre uma página de detalhe com problema, solução, tecnologias, o meu papel e resultado

4. Infraestrutura e Segurança: laboratórios e competências em Windows Server 2022, Active Directory, virtualização, Docker, Linux e fundamentos de cibersegurança

5. Competências: agrupadas em Linguagens (Java, PHP, JavaScript, Python, C/C++/C#, Kotlin), Frameworks (Laravel, Node.js, WordPress), Infraestrutura (Docker, VirtualBox, VMware, Windows Server, Linux, Active Directory), Dados e Formulários (ODK, XLSForm, KoBoToolbox, Survey123) e Automação (n8n, LLMs)

6. Formação e Percurso: linha cronológica

7. Contacto: email, LinkedIn, GitHub e formulário simples

8. Rodapé

1. ALKINI: sistema de gestão de stock e utilizadores desenvolvido em Laravel e administrado em servidor Linux. Inclui registo de utilizadores, envio de emails e administração via SSH. Tecnologias: Laravel, PHP, Linux, SMTP.
